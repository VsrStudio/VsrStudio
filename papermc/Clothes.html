Clothes

Clothes is a creative plugin for PaperMC that brings customizable clothing and skins to your server. With unique features and mechanics, it allows players to enhance their in-game appearance and style.

Features

  • Customizable clothes and outfits
  • Support for multiple player models
  • Interactive clothing shop system
  • Dynamic skin changes
  • Seamless PaperMC server integration
