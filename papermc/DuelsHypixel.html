DuelsHypixel

DuelsHypixel is a competitive and fun plugin for PaperMC that brings the exciting Duels gameplay to your server. With custom features and mechanics, it allows players to challenge each other in intense one-on-one battles.

Features

  • Customizable duel maps and arenas
  • One-on-one PvP combat with ranking system
  • Leaderboard tracking for competitive players
  • Easy-to-use match queue system
  • Seamless PaperMC server integration
