Parkour

Parkour is a thrilling plugin for PaperMC that introduces challenging parkour courses to your server. It features custom maps, timed challenges, and rewards for the best parkour players.

Features

  • Customizable parkour courses
  • Timed runs with leaderboards
  • Reward system for completing challenges
  • Integration with server economy
  • Seamless PaperMC server compatibility
