VPNetwork Pocketmine

VPNetwork Pocketmine is a powerful plugin for PocketMine servers, enabling advanced features like enhanced networking, multiprotocol support, proxy support, and custom connectivity options. The plugin integrates seamlessly with ProtocolLib to enhance server performance.

Dependency: ProtocolLib

Features

  • Supports advanced networking features for PocketMine servers
  • Enables multiprotocol for better server management
  • Customizable networking options for optimized performance
  • Seamless integration with ProtocolLib
  • Enhances server scalability and performance
  • This plugin remake api 3 to api 5
