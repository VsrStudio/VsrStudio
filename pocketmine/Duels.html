Duels

Duels is an exciting plugin for PocketMine-MP servers that enables players to challenge each other in intense one-on-one battles. With customizable arenas, leaderboards, and rewards, Duels is perfect for competitive players and server communities.

Features

  • Create and manage multiple duel arenas
  • Customizable kits and settings for each duel
  • Real-time leaderboards to track top players
  • Support for rewards upon duel completion
  • Highly optimized for low-latency gameplay
  • Easy-to-use commands and intuitive setup
  • Fully supports PocketMine API version 5
