Crates 3D

Crates 3D is an advanced plugin for PocketMine-MP servers that introduces interactive 3D crate models. Players can interact with these crates to receive rewards in an engaging and visually appealing manner.

Features

  • Fully customizable 3D crate models
  • Interactive animations when opening crates
  • Supports unlimited reward tiers
  • Integrates seamlessly with other plugins
  • Lightweight and optimized for performance
  • Simple configuration and setup process
  • Fully supports PocketMine API version 5
