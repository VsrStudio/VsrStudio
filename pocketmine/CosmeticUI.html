CosmeticUI

CosmeticUI is a versatile plugin for PocketMine-MP servers that provides a user-friendly interface to manage cosmetics like particles, wings, and more. Designed to enhance player experience with customizable options.

Dependencies: This plugin requires the Costumis plugin to function properly.

Dependencies: This plugin requires the Costumis plugin to function properly.

Features

  • Customizable cosmetic options for players
  • Intuitive user interface with multiple categories
  • Integration with other PocketMine plugins
  • Lightweight and optimized for performance
  • Fully supports PocketMine API version 5
  • Thanks to @odidak
