Informasi lengkap berbagai varian dari PocketMine-MP untuk server Minecraft: Bedrock Edition.

🔧 PocketMine (Recode)

🔹 PM5 Official

  • Versi resmi terbaru dari PocketMine-MP dengan API 5.
  • Mendukung Minecraft Bedrock Edition versi stabil terbaru.
  • Update langsung dari tim PMMP.
  • Dukungan plugin modern berbasis API 5.
🔗 GitHub: PocketMine-MP 5

🔹 PM4 Official

  • Versi lama PocketMine-MP dengan API 4.
  • Tidak lagi mendapatkan pembaruan resmi dari PMMP.
  • Kompatibel dengan plugin-plugin lama.
  • Stabil di Minecraft versi 1.19 ke bawah.
🔗 GitHub: PocketMine-MP 4

🔹 PM4V2 Unofficial

  • Modifikasi dari PM4 yang mendukung Minecraft 1.21.70.
  • Diperbarui oleh komunitas atau pengembang pihak ketiga.
  • Tidak dikembangkan oleh tim PMMP resmi.
🔗 GitHub: PocketMine-MP-Legacy

⚒️ Fork PocketMine

🔹 NG (NetherGames) Unofficial

  • Fork dari PocketMine yang dikembangkan oleh tim NetherGames.
  • Mendukung MultiVersion, memungkinkan pemain dari berbagai versi Minecraft untuk bergabung.
  • Stabil dan banyak digunakan untuk server berskala besar.
🔗 GitHub: PocketMine-MP

🔹 BA (BetterAltay)

  • Fork dari PocketMine-MP berbasis proyek Altay.
  • Masih Menggunakan PM3/API 3 dan Support Minecraft Versi Terbaru.
  • Menambahkan fitur seperti full NBT support, BlockEntity, dan lainnya seperti Vanilla cocok untuk server survival.
  • Cocok untuk server dengan kebutuhan fitur lanjutan dan performa tinggi.
🔗 GitHub: BetterAltay
